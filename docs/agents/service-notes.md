Thumbnails/previews live on SSD NFS (sdb) — do NOT move to block storage (HDD sdc = slower + the contended IO domain). **Background-job concurrency is capped to protect sdc** (DB-managed system-config, `system_metadata` key `system-config`, JSONB `job.*.concurrency`; re-set on fresh install): `thumbnailGeneration=2`, `metadataExtraction=2`, `library=2` — these jobs read ORIGINALS off the HDD library. Put the SAME selector on both. **The rule this note was written about kept the fault for another month** (found 2026-09-19, bead code-q9iy): `add-keel-annotations` carried `namespaceSelector: keel.sh/enrolled=true` on `match` and a bare `targets` list of Deployment/StatefulSet/DaemonSet, so the background controller annotated every workload in the cluster.
